# Figuras de las constelaciones (modificadas)

Las ilustraciones de las constelaciones que usa la app **Cielario**, tal como
van dentro de ella.

- **Original:** ilustraciones de Johan Meuris para Stellarium (cultura del
  cielo «modern»):
  https://github.com/Stellarium/stellarium/tree/master/skycultures/modern
- **Licencia de las ilustraciones:** Licencia Arte Libre 1.3
  (https://artlibre.org/licence/lal/es/). Estas copias modificadas se
  distribuyen con la misma licencia.
- **Datos de anclaje** (`constellation_art.json`): del equipo de Stellarium,
  CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). Esta
  versión se distribuye con la misma licencia.

## Cambios

Pasadas a escala de grises, con el contraste estirado (gamma 1,6) y guardadas
en WebP. Las estrellas de anclaje se han emparejado con el Bright Star
Catalogue mediante el HD-DM-GC-HR-HIP-Bayer-Flamsteed Cross Index (Kostjuk
2002, CDS IV/27A). En la app se tiñen y se dibujan con poca opacidad sobre el
cielo.
